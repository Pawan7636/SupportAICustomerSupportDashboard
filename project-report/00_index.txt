================================================================
  QUICK REFERENCE — KEY FACTS
================================================================

PROJECT TYPE     Full-stack AI-powered customer support SaaS
FRONTEND         React 19 + Vite 8 + Tailwind CSS v4
BACKEND          Node.js 22 + Express 4 + TypeScript 5.7
DATABASE         SQLite (node:sqlite, WAL mode)
AI MODEL         Google Gemini 3.8 Flash (chat)
EMBEDDING MODEL  text-embedding-004 (768 dims, RAG)
AUTH             JWT HS256, bcrypt, refresh token rotation
FRONTEND URL     http://localhost:8443 (dev)
BACKEND URL      http://localhost:3001 (dev)
API PREFIX       /api/...

SCREENS
  Dashboard, AI Assistant, Human Escalation,
  Knowledge Base, Query History, Escalations

BACKEND ROUTES
  /api/auth       Registration, login, refresh, logout, me
  /api/users      User management (admin)
  /api/tickets    Ticket CRUD, status, assign, audit
  /api/tickets/:id/replies   Reply + internal note CRUD
  /api/kb         Knowledge base CRUD + semantic search
  /api/chat       AI response generation (RAG + Gemini)

USER ROLES       customer < agent < admin

RAG PIPELINE
  User query
  → embed with text-embedding-004 (768-dim)
  → cosine similarity vs all KB article embeddings
  → top-3 articles above 0.5 threshold
  → inject into Gemini system prompt
  → stream response via SSE
  → return source citations to frontend

RETRY LOGIC
  3 retries with exponential backoff (800ms base)
  on 503 Service Unavailable and 429 Rate Limited
  errors from Google Gemini API

DEPLOY
  Backend  → Render Web Service + Persistent Disk
  Frontend → Vercel Static + /api rewrite to Render
