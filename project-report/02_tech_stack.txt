  SUPPORTAI — TECH STACK

================================================================
  FRONTEND
================================================================

RUNTIME / BUILD TOOL
  Vite 8                     Ultra-fast dev server and bundler
  TypeScript 5.7             Strict typing across the codebase

UI FRAMEWORK
  React 19                   Component-based UI with concurrent features
  Single-file SPA            All screens in src/App.tsx — no routing library

STYLING
  Tailwind CSS v4            Utility-first CSS framework
  @tailwindcss/vite          Zero-config Vite plugin (no tailwind.config.js)
  Custom CSS variables       Design tokens in src/index.css (:root)
  Google Fonts (Inter)       Typography

ICONS
  lucide-react 1.67          SVG icon library (tree-shakeable)

STATE MANAGEMENT
  React useState / useMemo   Built-in React hooks — no Redux or Zustand needed
  No routing library         Screen controlled by a single `screen` state string

HTTP / STREAMING
  Fetch API                  Native browser fetch for all API calls
  ReadableStream / SSE        Server-Sent Events for streaming AI responses
  Relative URLs              API_BASE = "" — requests proxy through Vite

================================================================
  BACKEND
================================================================

RUNTIME
  Node.js 22.5+              Required for built-in node:sqlite support
  TypeScript 5.7             Compiled to CommonJS via tsc
  tsx (dev)                  Hot-reload TypeScript execution in development

WEB FRAMEWORK
  Express 4                  HTTP server and routing
  helmet                     Security headers (XSS, HSTS, etc.)
  cors                       Cross-Origin Resource Sharing
  morgan                     HTTP request logging
  express-rate-limit         Global (200/15min) and auth (20/15min) rate limiting

DATABASE
  SQLite (node:sqlite)       Node.js built-in SQLite — no native compilation
  WAL journal mode           Better concurrent read performance
  Foreign keys ON            Referential integrity enforced
  Auto-migration             Schema applied idempotently on every server start

AUTHENTICATION
  jose 5.9                   RFC-compliant JWT library (HS256)
  bcryptjs 2.4               Password hashing (cost factor 10–12)
  Access token               HS256, expires 15 minutes
  Refresh token              HS256, expires 7 days, rotation enforced
  Token storage              SHA-256 hashed in DB — raw token never persisted

VALIDATION
  zod 3.23                   Schema validation for all request bodies/params

ID GENERATION
  uuid v4                    Cryptographically random IDs for all records

AI / ML
  @google/generative-ai      Official Google Generative AI SDK (0.21.0)
  Gemini 3.8 Flash           Chat response generation (configurable)
  text-embedding-004         768-dimension text embeddings for RAG
  Cosine similarity          Pure JavaScript — no native vector library needed

LOGGING
  Custom structured logger   JSON-formatted logs with timestamps and levels
